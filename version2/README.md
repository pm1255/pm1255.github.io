# Miao Pan's Academic Homepage

This repository contains the source code for Miao Pan's personal academic website.

Website: [https://pm1255.github.io/](https://pm1255.github.io/)

The live preview is available at [pm1255.github.io](https://pm1255.github.io/).

The website presents Miao Pan's research interests, publications, awards, and academic experience.

## Open-source projects

- [Scene-Designer](https://github.com/ZJU-OmniAI/Scene-Designer) · [project page](https://zju-omniai.github.io/Scene-Designer/)
- [Spatial-Interactor](https://github.com/ZJU-OmniAI/Spatial-Interactor) · [project page](https://zju-omniai.github.io/Spatial-Interactor/)
- [Show, Don't Tell / ProVisE](https://github.com/ZJU-OmniAI/ProVisE) · [project page](https://zju-omniai.github.io/ProVisE/)

The homepage labels these as public code and links to the official project pages. Check each repository for its current license and third-party asset terms.
