# Website versions

The root of this repository is the redesigned **version 2** homepage that powers `pm1255.github.io`.

- `version1/` preserves the original homepage before the redesign.
- `version2/` is a self-contained copy of the redesigned homepage.
- The root files mirror `version2/` so GitHub Pages keeps serving the redesigned site.

Both archived folders keep their own `contents/` and `static/` paths, so they can be previewed directly from GitHub Pages.
